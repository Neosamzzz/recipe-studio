# 配方工作室

本地配方梳理工具，使用占位 Item，可自建物品及绑定 PNG 图标。

## 启动

双击 `启动.command`，或在本目录执行 `python3 -m http.server 8766 --bind 127.0.0.1`，浏览器访问 http://127.0.0.1:8766/ 。需要 Python 3；关闭服务终端即停止服务。

## 操作

任意位置单击 Item（目录、最近栏、工作区或配方预览），右上显示物品属性，右下显示其配方；点击底图、空槽位或空白后返回对应对象属性。

- 左上 Item 目录：展开分类、搜索、点击查配方、拖入槽位。右键目录新建 Item 或子目录，分类以 `/` 分层；右键 Item 绑定图标。目录树下方一行显示最近成功拖入槽位的 Item，可直接拖取；重复使用移到最前，最多保留 20 项，并随工程保存。
- 左下文件与素材：用可展开目录树浏览文件，右键导入本机文件夹或图片，文件可拖入工作区。模板与已存配方位于独立的“合成面板模板”面板。
- 工作区：左键拖空白平移，滚轮缩放，右键拖动框选：从左往右为蓝色实线完整包含，从右往左为绿色虚线相交选择；组合配方按整体边界判断。左键拖选中底图整体移动。Item 拿取时图标与数量跟随鼠标：从库里拖出为复制，从槽位拿出为移动；放入已有物品的槽位会交换，取消或放到工作区外则还原。Item 也可独立放在工作区，再拖入槽位。Shift 点击可增减选择。
- 自定义模板：拖入底图，开启“放置槽点”后点击底图加槽；关闭后可拖动对齐或通过属性精确定位。右键拖动框选对象，再右键“组合为模板／组合为配方”；普通选中不显示组合操作。
- 配方：设置投入与产出槽并填入 Item，右键产出 Item 保存配方；点击 Item 在右下查看配方，产出显示于标题旁，可把整张配方作为整体加入工作区，拖动底图移动整组，右键底图“解耦该配方”后可单独移动内部对象；右键槽位切换输入／输出，只显示另一种状态。同一 Item 的多条配方通过“前一个／下一个”切换；“删除该配方”只删除当前配方，不删除 Item、模板或工作区对象。
- 保存：使用“保存工程”导出 JSON；“打开工程”恢复。工程包含自建 Item、分类、图标、底图、工作区、模板及配方。退出前请保存，页面不自动保存。

本工具不修改 Minecraft 文件，也不直接注册游戏物品或导出模组配方。
